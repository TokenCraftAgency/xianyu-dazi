## 使用流程

**三步开始采集** —— 无需任何配置，下载即用。

### 01 · 登录闲鱼

在应用内置的浏览器窗口中登录你的闲鱼账号，登录状态自动同步到采集任务。

### 02 · 创建采集任务

输入关键词，配置价格区间、排序方式与采集上限，一键启动，自动连续采集。

### 03 · 查看采集结果（会员专属）

采集结果自动保存，在数据中心分页管理与查询，在数据看板洞察热门卖家与关键词趋势。
